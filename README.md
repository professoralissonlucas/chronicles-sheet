# Chronicles & Sheet

Ferramenta web para jogadores de **RPG de mesa**. Reúne numa só página a ficha do personagem (vida, sanidade, esforço e atributos), o inventário, um rolador de dados e um diário de campanha com tags e busca. Tem dois visuais: **Ficha de Campo** (moderno) e **Diário Manuscrito** (pergaminho).

**Acesse:** https://professoralissonlucas.github.io/chronicles-sheet/

## Créditos

Projeto criado pelas alunas **Ana Lívia** e **Zarpelon**.

## Como usar

- Abra o link acima, ou abra o arquivo `index.html` direto no navegador. Não precisa instalar nada.
- Tudo o que você preencher é salvo automaticamente **no seu navegador**.
- **Exportar Backup** baixa um arquivo `.json` com todos os dados. Use **Importar Backup** para recuperá-los ou levá-los para outro computador.
- O botão no topo troca entre os dois modos. No modo Ficha de Campo aparece o rolador de dados; no modo Diário Manuscrito aparece o diário.

## Tecnologia

HTML, CSS e JavaScript puro, sem bibliotecas e sem servidor. Os detalhes técnicos estão em [SPEC.md](SPEC.md).
